# Philadelphia County, PA — Social Services Listing Audits

**All categories checked: 2026-11-01. Status: staged for publication in
Keith's own repo first. Nothing in this audit has been sent to PA 211
or any organisation as a direct message.**

## What this is
One county, twelve public categories — a dated curation audit of
public social-services listings for Philadelphia County, PA (the City
of Philadelphia; city and county are coterminous), checked against the
organisations' own websites and other public listings. It is not a
replacement directory: it does not claim to be a current list of open
services, and it should not be used as one without checking with the
organisation or PA 211 first.

Each category folder holds three files: a README with the headline
corrections, the full audit report with evidence and sources, and the
original pilot list it was checked against.

## Method and limits — please read before using this
- Public web search and page-text fetch only, 2026-11-01. No
  organisation, PA 211, or anyone else was contacted for these audits.
- An organisation's own website is treated as authoritative over
  third-party directories.
- **No service is called defunct or closed in these audits.** A failed
  or missing page is reported as unverified, never as closure.
- Fares, schedules, waitlists, funding windows, and seasonal dates are
  date-stamped to 2026-11-01 and must not be presented as permanent.
- For mental health, substance use, and legal aid, contact information
  only was audited — no advice was rewritten.
- No bed availability is stated as a static fact anywhere in these
  audits; intake phone/process only.
- **Partial pilots, stated plainly:** PA 211's search pages are
  JavaScript-driven, and text fetch on 2026-11-01 did not return a
  complete, Philadelphia-filtered PA 211 result list for any category.
  Each pilot is therefore anchored on retrievable PA 211 items plus
  clearly-labelled secondary lists and own sites, filtered by exact
  address (a Philadelphia postal address alone was not treated as
  proof of county). These are partial pilots, not complete county
  directories, and must not be presented as complete.
- **Re-checks needed before any outward send:** each report flags its
  own pre-send re-check list (notably: food — a live-browser check of
  search.pa211.org for Philadelphia County; mental health — Friends
  CRC phone conflict and HUP Cedar number; utilities — LIHEAP
  2026–27 opening on Nov 2, 2026, and the PGW Hardship contradiction;
  transportation — SEPTA Shared-Ride fare and MATP scheduling number;
  shelters — House of Passage phone and Code Blue warming-centre
  process; legal aid — intake windows and suite numbers; seniors —
  ombudsman holder and centre phones; disability — Vision for
  Equality programme line and OVR/BBVS suites; substance use —
  programme phones and UNVERIFIED items; housing — PHA waitlists and
  FreshStartPHL open status; employment — CareerLink addresses and
  phones; child care — PHLpreK current cycle and aggregator hours).
  Before sending, re-check the items each report flags, and re-run a
  live-browser PA 211 Philadelphia check.
- The auditor is NOT a local resident of Philadelphia County; this is
  county-by-county checking of public listings.
- These audits were prepared with AI assistance. Corrections,
  challenges, and updates from statewide PA 211 or the organisations
  themselves are welcome — that is the point of staging them here first.
