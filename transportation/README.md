# Philadelphia County — Transportation

Date checked: 2026-11-01. Status: NOT SENT — staged only. Nothing here has been submitted to PA 211 or to any organisation.

## Headline corrections (date-stamped 2026-11-01; fares/schedules are not permanent)

- SEPTA paratransit fare is $5.75 one-way, not $4.25. Older sources still show $4.25 for SEPTA Access ADA / Shared-Ride; SEPTA's own ADA page (fetched 2026-11-01) states $5.75, following the September 2025 tariff change that also removed the 75-cent county surcharge.
- Philadelphia County MATP broker branding is now Modivcare (formerly LogistiCare). MATP is medical-only — Medical Assistance-covered services — not general public transport. SEPTA Access, by contrast, is explicitly not medical transport on SEPTA's own site. Do not blur the two.
- Pennsylvania Prison Society bus from Philadelphia now serves nine state institutions (SCI Benner, Frackville, Greene, Huntingdon, Laurel Highlands, Mahanoy, Muncy, Smithfield, Somerset) at $20 round trip, children under 18 free — not "all facilities except Camp Hill, Chester, Graterford" as older directory text states.
- City Zero Fare (free SEPTA for low-income residents age 18–64) is not currently enrolling new participants (City page, 2026-10-13); it uses lottery/auto-enrolment.
- Former name alert: "CCT Connect" is now SEPTA Access.

## Method and limits

Directory: statewide PA 211 (pa211.org / search.pa211.org). Each listing was checked against the organisation's own website where possible; own site beats directory, directory beats aggregator. Public web only; no organisation was contacted.

Limit: PA 211 search pages are JavaScript-driven and text fetch returned snippets, not complete per-record detail. This pilot is anchored on PA 211 items actually retrieved plus clearly-labelled secondary lists and is NOT a complete Philadelphia County transportation list. No organisation was called closed/defunct from a failed page load — unretrieved details are marked UNVERIFIED. All fares/schedules are date-stamped 2026-11-01 and must be re-checked before any send; see the pre-send re-check list in the audit report.
