# Philadelphia County — Child care / family support

**County:** Philadelphia County, PA · **Category:** Child care / family support · **Checked:** 2026-11-01
**Directory:** Statewide PA 211 (pa211.org / search.pa211.org)
**Status: NOT SENT — staged only.** Nothing in this folder has been submitted to PA 211 or to any organisation.

## Method and limits
Public web only (search + page-text fetch, 2026-11-01). No organisation was contacted. Own site beats directory; directory beats aggregator.

Important limit: PA 211 search pages are JavaScript-driven and text fetch did not return a complete Philadelphia child-care list. Only two PA 211 records were retrieved in full (Congreso ELECT and Congreso Harcum, both confirmed). The rest of this pilot is anchored on providers' own sites and City of Philadelphia pages, with aggregator records flagged as such. **This is a partial pilot of 29 items, not a complete county directory.**

No information about individual children is included. No waitlist status is claimed for any listing, because none was stated on a provider's own site retrieved. No centre is called closed on the basis of a failed page load.

All three are excluded here on exact address, despite their Philadelphia-labelled pages.

Current ELRC income thresholds were not found (only a 2019 table) and the City PHLpreK page text as retrieved cites the 2025-2026 cycle — both must be re-checked before any send.
