# Philadelphia County — Child care / family support — Pilot list
Checked 2026-11-01. Directory: statewide PA 211 (pa211.org / search.pa211.org).
Status: NOT SENT. Staged only. No organisation was contacted.

## Scope note — read first
- Philadelphia city and county are coterminous. A Philadelphia postal address alone was NOT treated as proof of county; exact addresses were checked.
- PA 211 search pages are JavaScript-driven. Two PA 211 records were retrieved in full by text fetch (Congreso ELECT and Congreso Harcum — see checks-batch1.md); the wider PA 211 child-care search listing did not return a complete, citable Philadelphia list by text fetch. This pilot is therefore anchored on those two verified PA 211 records PLUS clearly-labelled secondary lists (providers' own location pages, City of Philadelphia PHLpreK pages, and directory aggregators used only where an own site was unavailable). This is a partial pilot, NOT a complete Philadelphia County child-care directory.
- No information about individual children is included. No waitlist status is stated unless a provider's own site stated it; none in this pilot did, so waitlist is "not stated" throughout.
- The auditor is not described as a local resident of Philadelphia County.
