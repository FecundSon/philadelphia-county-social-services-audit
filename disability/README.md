# Philadelphia County, PA — Disability services

**Date checked:** 2026-11-01
**Status: NOT SENT.** Staged only. Nothing here has been submitted to PA 211 or to any organisation.
**Method:** Public web only (search + page-text fetch). Own site beats directory; directory beats aggregator. A failed or incomplete page load was never treated as closure. Philadelphia city and county are coterminous; listings were filtered by exact address, not by postal address alone. Statewide/regional services are labelled as such; no local office was invented for them.

## Counts

- **Reviewed: 33 listings — 28 in-scope pilot + 5 out of scope / statewide-only.**
- **In-scope verdicts: CONFIRMED 12, CORRECTED 4, CLARIFIED 9, UNVERIFIED 3.**
- This is a **partial pilot, not a complete county directory**: PA 211 search pages are JavaScript-driven and returned partial, statewide-mixed results in text fetch, so the pilot is anchored on retrievable PA 211 items plus clearly-labelled secondary lists and own sites.
